Deployment Guide

Fast Master Binary Installation (Single Command)

Deploy the Master Monitoring Application Server in under 3 minutes with zero manual setup required.

Step 1: Install Master Dashboard Server

Run the installer script or self-extracting binary executable on your Master Linux Server as root:

sudo ./install.sh
✔ Automatically installs Nginx, Gunicorn, Python virtualenv dependencies.
✔ Auto-checks and selects an available HTTP port if 8088 is occupied.
✔ Access Web UI at: http://<MASTER_IP>:8088

Step 2: Run Health Scan on Client Node

Run the lightweight standalone client agent on any Linux node you want to monitor:

sudo ./health-check
✔ Prompts for Master Server URL on first run and saves config to /etc/health-check.conf.
✔ Performs health check in ~3 seconds and uploads HTML/TXT/JSON reports to Master Server.

Step 3: Schedule Automated Periodic Scans

To schedule daily health scans automatically at 2:00 AM via crontab:

0 2 * * * /usr/local/bin/health-check >/dev/null 2>&1
Got Questions?

Frequently Asked Questions

Everything you need to know about licensing, offline execution, and disaster recovery.

Q1: Does license validation work on offline / air-gapped Master Servers?
YES, 100%! License validation is computed purely locally using cryptographic digital signatures. It never calls external internet APIs, phone-home servers, or third-party cloud services. Works completely offline in secure air-gapped data centers.
Q2: What happens if the Master Application Server crashes or goes offline?
Client agents operate independently and will never disrupt client server operations. Scans continue to generate local reports in /var/log/health-check/. You can restore a crashed Master Server in 2 minutes by running install.sh on a new VM and restoring your backed-up host reports (/var/www/html/health-reports/), user database (users.json), and license backup (/etc/health-dashboard.license.backup).
Q3: What happens when a commercial license reaches its expiration date?
Upon expiration, the platform enters a 14-Day Renewal Grace Period where all active servers continue scanning normally while displaying a renewal reminder. After 14 days, upload capacity falls back to the Free Community Edition limit (10 earliest registered servers). ALL historical scan data and past reports remain 100% accessible, viewable, and searchable forever!
Q4: Does the client agent file run continuously as a background daemon?
No! The client agent is an on-demand execution script that finishes scanning in ~3 seconds and exits immediately. It consumes 0% RAM and 0% CPU when idle. Periodic scans are scheduled via standard Linux cron.
Q5: What if a client accidentally deletes their license.key file?
The Master Server automatically maintains a self-healing configuration backup at /etc/health-dashboard.license.backup. If a customer accidentally deletes license.key, the Master Server automatically restores it upon the next request!
