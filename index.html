Deployment Guide

Fast Master Application Installation

Deploy the InfraSight Master Monitoring Server in under 3 minutes with zero manual setup required.

Step 1: Install InfraSight Master Application

Download and run the self-extracting application package on your Master Linux Server as root:

chmod +x infrasight-installer.run && sudo ./infrasight-installer.run
✔ Closed-source self-extracting application package (infrasight-installer.run).
✔ Automatically installs Nginx, Gunicorn, Python virtualenv at /opt/infrasight.
✔ Pre-configures client agent application (infrasight-agent) for enterprise host distribution.
✔ Access Web UI at: http://<MASTER_IP>:8088

Step 2: Run Agent Application on Client Server

Run the standalone executable application (C binary compiled via gcc/shc) on any Linux server (RHEL, Ubuntu, Debian, Oracle, SUSE, Amazon Linux):

sudo ./infrasight-agent
✔ Ships as a compiled application — completely hides bash source code from end users on node servers.
✔ Prompts for Master Server URL on first run and saves configuration securely.
✔ Performs health scan in ~3 seconds and uploads HTML/TXT/JSON reports to Master Server.

Step 3: Schedule Automated Periodic Scans

To schedule daily health scans automatically at 2:00 AM via crontab:

0 2 * * * /usr/local/bin/infrasight-agent >/dev/null 2>&1

Got Questions?

Frequently Asked Questions

Everything you need to know about licensing, offline execution, and disaster recovery.

Q1: Does license validation work on offline / air-gapped Master Servers?
YES, 100%! License validation is computed purely locally using cryptographic digital signatures. It never calls external internet APIs, phone-home servers, or third-party cloud services. Works completely offline in secure air-gapped data centers.
Q2: Can I run client scans over a Private IP without Internet?
YES! Client servers can upload reports to the Master Server's Private IP (e.g. http://10.0.27.53:8088/upload). No public IP or internet access is needed.
Q3: What happens when a commercial license reaches its expiration date?
Upon expiration, the platform enters a 14-Day Renewal Grace Period where all active servers continue scanning normally while displaying a renewal reminder. After 14 days, upload capacity falls back to the Free Community Edition limit (10 earliest registered servers). ALL historical scan data and past reports remain 100% accessible, viewable, and searchable forever!
Q4: Does the client agent file run continuously as a background daemon?
No! The client agent (health-check executable) is an on-demand binary execution file that finishes scanning in ~3 seconds and exits immediately. It consumes 0% RAM and 0% CPU when idle.
Q5: How does client organization and project scope binding work?
Licenses are cryptographically bound to your specific Client Organization Name and Project Scope. This ensures a license issued for one project cannot be reused across unauthorized projects.
